# M6-UI 简报：控制页与桌宠视觉重做（用户 2026-11-11 实机截图反馈「太丑了」）

## 背景
M6 一期功能已全通，但 control.css 是无设计系统的裸样式（白底、默认按钮、纯文字列表），用户看完截图明确要求重做 UI。本简报只改视觉层：apps/desktop 的 control.html / control.css / pet.html 内联样式 / boot.html 样式，以及 control.mjs、pet.mjs 中**纯展示性**的 DOM 结构（如给商店条目加卡片容器、给动作按钮加分组标题）。功能逻辑、IPC、数据结构、文案语义一律不动。

## 设计方向（定死，不要自由发挥成另一套）
定位：给妻子用的陪伴桌宠，气质＝**温暖、柔软、干净的生活感应用**，不是开发者工具。

- **配色**：以角色主题绿 `#7fae7a`（肖大大主题色，源自 Mac 版定版）为品牌色推导整套色板：深绿标题栏 `#2f4f43` 一类深色只许用在顶栏；页面背景用暖米白 `#faf7f1`；卡片纯白、圆角 16px、柔和阴影（低透明度、大模糊）；次级绿用于页签选中态与主按钮；积分/价格等数字用暖橙 `#e8a04c` 点缀；危险/失败用柔和红 `#d9534f` 的浅色版。禁止再出现系统默认灰按钮与纯黑文字堆。
- **字体与排版**：字体栈 `"PingFang SC","Microsoft YaHei","Segoe UI",sans-serif`；标题 20–22px、正文 14–15px、行高 1.6；页面最大宽度与留白规范化，区块间距成体系（8/16/24）。
- **组件**：
  - 顶栏：深绿底、白字、圆角下沿或阴影；右侧放当前状态小圆点（按聚合状态着色：working 蓝、waiting 橙、done 绿、error 红、idle 灰）＋状态文字。
  - 页签：胶囊形，选中态绿底白字，未选中白底描边；不要再用方角默认按钮。
  - 概览条（连接页顶部）：做成一条横向数据卡：四到五个指标分格（状态/今日完成/积分/饥饿/击键），数字大、标签小；饥饿用一条小进度条呈现（≤100）。
  - 工具卡（Claude Code / Codex / 通用）：白卡片，左上角状态徽标（已启用绿点/未开启灰点），按钮主次分明（启用＝实心绿，测试＝描边）。
  - 陪伴页：顶部积分与饥饿做成两张并排小卡（积分卡带橙色数字、饥饿卡带进度条）；商店改为**网格卡片**（每种食物一卡：名称、份数与每份恢复、整包价格徽标、购买按钮），买不起的按钮置灰并写「积分不足」；背包同样卡片化，有份数的才亮投喂按钮。
  - 动作页：按钮改为圆角 chip 网格，按「状态动作 / 吃法 / 表情」分组带小标题；表情预览卡保留图片，卡片统一圆角与阴影。
  - 宠物页（设置）：表单成行对齐，滑杆与开关用主题色（accent-color），分区小标题。
  - 通知/诊断页：沿用同一套卡片与按钮规范，日志区等宽字体＋浅灰底圆角块。
  - 向导（首次启动）：卡片居中、留白加大，主按钮突出。
  - boot 页：同色板，阶段列表带状态圆点（进行中转圈或脉冲、成功绿勾、失败红叉用 CSS/SVG 实现，不引外部资源）。
- **桌宠窗口**：气泡改为圆角 18px 的浅色气泡＋细描边＋柔和阴影，尾巴小三角朝下（纯 CSS）；字体与控制页一致；不改窗口尺寸与拖动逻辑。
- **状态色一致性**：五态在顶栏圆点、会话列表、动作页的小圆点上用同一套颜色映射，映射表写进 RESULT。

## 红线
- 不改任何功能逻辑：IPC 命令与参数、snapshot 字段、companion 结算、启动编排、pet 播放与拖动、设置校验——全部不动。control.mjs/pet.mjs 只许调整展示结构与 class，不得改调用顺序与条件分支；改完既有测试必须仍全绿（测试若断言了 DOM 结构细节，按新结构同步更新测试并在 RESULT 里逐项说明，不许删测试绕过）。
- 不引外部资源：无 CDN、无网络字体、无图片文件新增（表情/帧图除外，它们已在包内）；图标只许内联 SVG 或 CSS 绘制。
- 中文文案不改口径（个别纯视觉分隔符可调）。
- 深色模式不做。窗口尺寸（控制 980×760、桌宠 300×350）不改。
