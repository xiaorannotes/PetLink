# M6 二期简报：聊天窗 + 打字跟随（Windows 助手）+ 看向鼠标（用户 2026-11-11 拍板开工）

## 背景
M6 一期（陪伴经济）与 UI2（可爱风米白重构，用户已认可大方向、细节待调）均已交付。本简报是 M6 简报 §二期规格 的落地版，三件事：聊天窗、打字跟随、看向鼠标。全部新 UI 必须长在 **UI2 设计系统**上（米白 `#FBF6EC`、奶白卡、蜜桃粉主按钮、奶油黄徽标、暖棕灰文字、全圆角胶囊与大圆角、内联 SVG 图标），不许回退到 UI1 的工具风。

前置事实（主控已核）：
- Hub 已有 source 注册表与事件模型（claude-code/codex/generic/sim），新增 `typing` source 沿用同一注册方式，不动既有 source 语义与五态协议。
- Mac 版打字计数 helper 是 darwin 专用二进制，Windows 必须新写；Mac 版 helper 的隐私口径（只计数、不读内容）是行为规格，Windows 版照此，原创实现。
- 人设默认文案的口径来源：Mac 版 `~/workspace/ai-buddy-mac/src/character-catalog.mjs` 与 `character-english.mjs` 里**肖大大自家人设部分**（名字、问候、语气——那是大宝自家 Muse 的人格设定，自家内容）；只许参照其口吻要点新写一版默认人设提示词，**不整段复制 AI Buddy 工程代码**，不搬官方角色文案。

## 一、聊天窗

- 入口两个：左侧竖导航新增「聊天」项（气泡 SVG 图标）；桌宠**双击**打开一个独立聊天小窗（360×480，无边框风格与桌宠一致、可拖动标题区、有关闭钮）。控制页聊天页与小窗共用同一套会话状态（主进程持有历史，两个 renderer 都只是视图）。
- 配置在「宠物」设置页新增「聊天设置」分区：接口地址（OpenAI 兼容 `/chat/completions`）、API Key（密码框；只存本机设置文件；**日志、诊断导出、boot.log 里一律脱敏为 ***，测试要覆盖**）、模型名、人设提示词（多行文本框，预置按上面口径新写的肖大大口吻默认文案，可改可恢复默认）。
- 通信：主进程 fetch 转发，renderer 不直连网络；请求带最近 N 轮历史（N=20 写死并在 RESULT 说明）；超时 30 秒；失败（网络/HTTP/超时）在聊天里显示一条柔和的错误气泡（原文案口径：说清是接口没通，不许假装已回复）。
- 未配置（无地址或无 Key）时：聊天页/小窗显示配置指引卡（按钮跳设置页对应分区），不发请求、不假聊。
- 桌宠联动：她发送消息后、等待回复期间，桌宠切 waiting 态气泡「想想哦……」一类现有等待文案口径；收到回复切 done 态一下再回落。只用现有状态与气泡机制，不新增协议状态。
- 历史只存内存＋本机设置同目录的 chat-history.json（最近 100 条），设置页提供「清空聊天记录」按钮。**聊天内容不进 boot.log、不进诊断导出。**
- 明确边界（设置页指引卡与 RESULT 都要写）：本窗接的是**可配置的模型接口**，不是肖大大本人的记忆与会话；接她本人是后续对接项，不在本期。

## 二、打字跟随（Windows 原生小助手）

- 形态：独立小进程 `PetLinkTyping.exe`，随包发布在 PetLink.exe 同目录；技术路线**优先 uiohook-napi 一类成熟 N-API 全局钩子库**（预编译、免装运行时）；若该路线在打包/体积上走不通，退到一个极小 C# WinForms 计数程序（.NET Framework 自带、免装）——选型与理由写进 RESULT，不许自研底层钩子驱动。
- 隐私铁律：**只统计按键次数**（含退格/空格一视同仁计 1），不记录键值、不记录窗口标题、不落盘任何内容；源码里不许出现把键码写日志/文件的路径，测试与代码审计点写进 RESULT。
- 上报：每 5 秒把本段计数经本机 HTTP POST 到 Hub 的 `typing` source（地址、端口、token 的发现方式沿用 Hub 既有本机接入约定，与 generic source 同一套）；PetLink 没开时静默重试，不弹窗、不报错。
- 呈现：Hub 聚合——最近 10 秒内 typing 计数 >0 且无更高优先级的真实会话状态时，桌宠呈现 working 跟随态，控制页概览今日击键改为真实累计（来自 typing source 当日事件求和），连接页工具区新增一张「打字跟随」卡：显示助手连接状态（已连接/未连接）与今日击键数，附「打开助手所在文件夹」按钮（指引手动启动）。
- 生命周期：主进程启动时**不自动拉起**助手（避免突兀）；控制页打字跟随卡提供「随 PetLink 启动助手」开关（默认关），开后主进程 spawn 同目录 exe 并在其退出时不重启；助手自身有托盘图标与退出菜单、无主窗口（或仅一个极简状态窗，RESULT 说明）。助手崩溃/缺失不影响 PetLink 任何既有功能（降级＝卡上显示未连接）。

## 三、看向鼠标

- pet 渲染层：主进程每 100ms 经 IPC 推鼠标屏幕坐标（或 pet 页用既有轮询通道，实现方式 RESULT 说明）；pet 页按鼠标相对桌宠中心的方向，对角色图做平滑变换：平移 ≤±5px、倾斜 ≤±2°、过渡 120ms linear；仅 idle/waiting 态生效，working 播放、拖动中、clip 播放中、气泡菜单打开时不叠加（避免与既有动画打架）。
- 设置页宠物分区加开关「看向鼠标」，默认开。
