# PetLink 本地重构验收（2026-11-11）

- 日常陪伴模式不要求配置 Codex/Claude，隐藏工具接入面板；Agent 搭档模式显示工具和真实会话状态，切换不会擅自修改工具配置。
- 默认安静站立；系统键盘/鼠标闲置 60 秒后睡觉，恢复操作后醒来。采用 Electron 系统闲置秒数，不读取按键内容。
- 摸摸回应播放一次，连续点击不重播、不排队；拖动不会触发摸摸。工作、睡眠可循环；等待、完成、出错、离线回应各播放一次。
- 工作：小键盘敲击；等待：托脸歪头；完成：拍手庆祝；出错：挠头摊手；离线：爱心挥别；睡眠：蜷在奶油软垫上熟睡。全程闭眼，不眨眼。
- 新增六段素材经百炼 video generate / download 生成下载；CLI 已获确认从 2.8.4 升级到 2.8.5。原生 30 FPS 经运动补帧输出 60 FPS；不是承诺所有设备实时渲染都不会丢帧。
- 旧姿态保留至新媒体可解码，180 毫秒淡化过渡，鼠标交互面继续保留。
- 打字计数集成到主进程，通过共享无参计数回调仅统计次数；可启用/停用，退出时清理监听。独立 PetLinkTyping.exe 已移出运行目录并保留备份，新打包脚本不再生成它。
- 右键投喂显示真实库存；空背包显示说明和商店入口，不自动购买，不制造假库存或积分。
- 原有 Windows 路径测试已移植；全量 Node 测试 155/155 通过。
- Windows 实机验证：两种模式、嵌入计数连接、闲置睡眠/唤醒、一次性回应、连续点击不重播、右键商店跳转、六段解码和透明背景、过渡完成均通过。测试中模拟闲置秒数验证阈值分支，结束已恢复真实系统 API。
