# M6-UI2 简报：可爱风 + 米白底，整个排版重构（用户 2026-11-11 二次反馈）

## 背景与上一轮结论
UI1（d656ea3）做了暖色卡片化，但用户看完截图的评价是：方向还要再调，并明确给出新口径——**「可爱风格、米白色，整个排版 UI 都重构」**。即：不是在 UI1 上微调，而是换一套排版骨架。功能逻辑、IPC、数据、文案口径、窗口尺寸（控制 980×760、桌宠 300×350）继续全部不动；本轮允许大改 control.html / boot.html 的 DOM 结构与 control.css，只保留 UI1 已验证的数据绑定与事件挂载点（id/命令名不变；必须改结构时，同步更新绑定代码与冒烟选择器并在 RESULT 逐项说明，不许删测试与断言）。

## 设计方向（定死）
定位：给妻子用的桌面陪伴宠，气质＝**可爱、软糯、像日系治愈系小工具**。关键词：圆、大圆角、软阴影、 pastel 点缀、留白呼吸感。

### 色板
- 页面底：米白 `#FBF6EC`（可带极淡的暖色径向渐变或小圆点纹理，CSS 实现，克制）。
- 卡片：奶白 `#FFFDF8`，边框用浅杏 `#F0E4CE` 1px，圆角 20–24px，阴影用暖色调柔和投影（rgba(180,140,80,.12) 一类），不要灰黑硬阴影。
- 主色（品牌/主按钮/选中态）：蜜桃粉 `#F6A8B8` 与角色绿 `#7FAE7A` 双主色：主按钮与页签选中用蜜桃粉渐变到 `#F28CA0`；状态「完成/done」与成功反馈保留绿；积分与价格点缀用奶油黄 `#F5C66B`（徽标底 `#FCEBC8`、字 `#8A6420` 深色保证可读）。
- 文字：主文字暖棕灰 `#5C4A3A`，次级 `#9A8874`；禁止纯黑与冷灰蓝。
- 顶栏：不再用深绿整条压顶。改为米白同底的轻顶栏：左侧放一个圆形头像位（用角色 idle 首帧小图，圆形裁切）＋「PetLink」圆体感标题＋副标题；右侧状态胶囊（浅底＋状态色圆点＋文字）。顶栏与内容之间用一条浅杏色分隔或柔和阴影即可。

### 字体与圆润感
- 字体栈：`"Yuanti SC","YouYuan","PingFang SC","Microsoft YaHei Rounded","Microsoft YaHei",sans-serif`（系统有什么用什么，不引外部字体）。
- 标题字重加粗、字号放大（页面主标题 24px），按钮与页签全部全圆角胶囊（border-radius: 999px），输入框圆角 12px 以上。

### 排版重构（骨架级，不是换色）
- **页签改左侧竖排导航**：窗口左侧一条 150–170px 的竖导航（奶白底、圆角内卡），每项＝小图标（内联 SVG，简单线条：链环、爱心、星星/动作、爪印、铃铛、扳手）＋文字，选中项蜜桃粉胶囊底白字；右侧为内容区滚动。窗口仍 980×760，内容区自适应剩余宽度。
- **连接页**：概览改为「大状态卡」：左侧圆形大头像（当前角色帧）＋当前状态大字＋一句陪伴语（用现有气泡文案口径，如 idle 的「陪你歇一会儿」，文案从现有来源取、不新编造数值），右侧四个小指标圆角块（今日完成/积分/饥饿带小进度条/今日击键）。工具卡改为纵向列表行：左侧彩色圆形图标位、中间名称与状态、右侧按钮组。
- **陪伴页**：顶部积分/饥饿做成两张大圆角横卡（积分卡奶油黄底、带星星 SVG；饥饿卡浅绿底＋圆头进度条）。商店网格卡：食物名加粗、价格做成奶油黄胶囊徽标、购买按钮蜜桃粉胶囊；买不起置灰。卡片可加一个小的分类色条（主食粉、零食黄、饮品蓝、甜点紫，按食物名归类即可，归类表写进 RESULT）。
- **动作页**：分组标题带小图标；状态动作 chip 带状态色圆点（映射沿用 UI1 的五态色）；表情卡圆角加大、图片居中、名称胶囊标签。
- **宠物/通知/诊断页**：沿用同骨架与组件；表单控件 accent-color 用蜜桃粉；日志区奶白底圆角块。
- **向导与 boot 页**：同色板同圆角；boot 阶段圆点改 pastel 版（进行中粉色脉冲、成功绿、失败柔红），居中卡片加大圆角。
- **桌宠气泡**：保持圆角气泡＋小尾巴，描边改浅杏色，底色奶白，可加极轻的暖色阴影；不改窗口与播放逻辑。

### 装饰纪律
- 装饰只许：内联 SVG 小图标、CSS 渐变/圆点纹理、角色自身帧图。不引外部图片与字体，不堆贴纸，不用 emoji 当图标（文案里原有的不算）。
- 可爱 ≠ 幼稚堆砌：每页装饰元素克制，信息层级仍然第一位；大宝是成年用户，避免幼儿园式配色（高饱和撞色禁止）。
